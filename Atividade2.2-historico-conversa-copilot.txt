Você vai me ajudar a implementar a TASK-QE-001 do projeto NovaTech Assistant.

Contexto técnico:

- TypeScript com strict mode

- Azure Functions v4

- Zod para validação

- pino para logging (NUNCA console.log)

- Toda resposta deve ter o campo `sourceDocuments` no JSON

Crie os seguintes arquivos exatamente nos caminhos indicados:

**`src/shared/types.ts`**

Deve conter as interfaces:

- `ConversationTurn` com campos `role: 'user' | 'assistant'` e `content: string`

- `QueryRequest` com campo obrigatório `question: string` e opcional `conversationHistory: ConversationTurn[]`

- `SourceDocument` com campos `documentId: string`, `section: string`, `version: string`

- `RetrievedChunk` com campos `content: string`, `score: number`, `metadata: SourceDocument`

- `QueryResponse` com campos obrigatórios `answer: string`, `sourceDocuments: SourceDocument[]`, `lowConfidence: boolean`

**`src/shared/errors.ts`**

Deve conter as classes:

- `AppError` extendendo `Error` com campo `statusCode: number`

- `ValidationError` extendendo `AppError` com `statusCode` fixo em 400

- `EmbeddingError` extendendo `AppError` com `statusCode` fixo em 502

- `SearchError` extendendo `AppError` com `statusCode` fixo em 502

- `CompletionError` extendendo `AppError` com `statusCode` fixo em 502

**`src/shared/logger.ts`**

Deve conter:

- Instância `pino` configurada com `level: 'info'` e `base: { service: 'novatech-assistant' }`

- Export default da instância

- Export nomeado `createRequestLogger` que recebe `requestId: string` e retorna logger filho com o requestId no contexto

**`src/functions/query/validator.ts`**

Deve conter:

- Schema Zod `QueryRequestSchema` que valida `question` como string obrigatória, mínimo 1 char após trim, máximo 2000 chars

- Schema Zod `QueryResponseSchema` que valida a estrutura de `QueryResponse`

- Função `validateQueryRequest(body: unknown)` que retorna `QueryRequest` ou lança `ValidationError` com os detalhes do Zod

- Os schemas Zod devem ser exportados além das funções

**`src/functions/query/handler.ts`**

Deve conter:

- Handler Azure Functions v4 registrado com `app.http('queryEndpoint', { methods: ['POST'], authLevel: 'anonymous', handler: ... })`

- O handler valida o body com `validateQueryRequest`

- Retorna HTTP 400 com `{ error: string, details: ZodIssue[] }` se validação falhar

- Retorna HTTP 200 com `QueryResponse` mockada (answer: "mock", sourceDocuments: [], lowConfidence: false) se validação passar

- Loga cada requisição com pino incluindo os campos `requestId`, `questionLength` e `durationMs`

- Usa `crypto.randomUUID()` para gerar `requestId`
