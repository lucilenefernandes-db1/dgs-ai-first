Enquanto isso, o script ingestao.py está pronto. Aqui está um resumo do que foi implementado:

Estrutura do script:

carregar_documentos(pasta) — lê todos os .md de docs, retorna lista com nome_arquivo e conteudo.

dividir_em_chunks(conteudo, nome_arquivo) — usa re.split(r'(?=^#{2,3} )') para quebrar nos cabeçalhos ##/###. Seções ≤ 600 tokens viram um chunk direto; seções maiores são subdivididas com overlap de 50 tokens via _subdividir_com_overlap(). A estimativa usa 1 token ≈ 4 caracteres.

gerar_e_indexar(chunks) — codifica todos os chunks em lote com modelo.encode() e persiste no ChromaDB via collection.upsert(). IDs no formato {arquivo}__idx{n} garantem idempotência ao re-executar.

ChromaDB configurado como PersistentClient em chroma_db, collection novatech_docs com espaço cosseno.

Execução principal itera os documentos, chama as três funções em sequência e imprime o total de chunks por arquivo + total geral.

Observação: o script usa o virtualenv do projeto (python.exe), não o Python 3.14 do sistema que não tem as dependências instaladas.
